# Privacy Policy — StarTab

**Last updated: 2026-05-12**

StarTab does not collect, transmit, or sell any personal data.

- All user data (settings, bookmarks, read-later items, trash) is stored locally using Chrome's built-in storage APIs (`chrome.storage.local` and `chrome.storage.sync`).
- `chrome.storage.sync` data is synced only through the user's own Google Account, as managed by Chrome. StarTab has no access to this sync infrastructure.
- Search queries entered in the StarTab search bar are forwarded to the user's **default search engine** via the Chrome Search API (`chrome.search.query`). StarTab does not intercept, log, or redirect these queries.
- Favicon images are loaded from Google's public favicon service (`google.com/s2/favicons`). Wallpaper images are loaded from URLs explicitly provided by the user.
- No analytics, tracking, cookies, or external network requests are made by this extension.
